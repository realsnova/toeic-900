## 3. 獨立審查

由沒參與實作的審查代理審查 `282e59a..6d88ca2` 的完整差異，對照規格。結果：沒有 P0／P1。

| 編號 | 問題 | 處理 |
|---|---|---|
| P2-1 | 會先思考的模型（Sonnet 5.5）可能把輸出上限用在思考上，測試連線只給 5 個 token 會得到空回應 | 解析上限改為 2,000、測試連線改為 64；只有思考沒有文字時顯示明確訊息。審查者建議送出特定的 `thinking` 參數，我沒有採用：無法確認該參數值正確，送錯會讓所有請求被拒 |
| P2-2 | 沒檢查 `stop_reason`，截斷的回應會被快取並記錄判定 | 只有 `end_turn` 才快取與記錄；截斷時顯示並標示不完整；拒答顯示錯誤訊息 |
| P3-1 | 清除疑似清單後，快取命中仍說「已記錄」但沒有記錄 | 快取命中時重新記錄 |
| P3-2 | 讀取回應內容時不在逾時範圍內 | 逾時計時涵蓋到讀完內容 |
| P3-3 | 快取鍵不含提示版本 | 加入 `AI_PROMPT_V` |
| P3-4 | 儲存設定失敗會拋出未處理的例外 | 改為回傳錯誤訊息 |
| 測試缺口 | `chosen` 索引與畫面行為沒有自動化測試 | 由第 2 節的瀏覽器測試涵蓋；v1.4 的 Playwright 端對端測試再自動化 |

每一項修正都有對應的回歸測試（`review-131` 開頭）。

## 4. 需要使用者執行（L6）

**T-AI-L6-1 真實 API 驗證（約 10 分鐘）**：
1. 到 [Anthropic 主控台](https://console.anthropic.com/settings/keys) 建立一把金鑰，建議同時設定每月用量上限。
2. 上線後在手機開啟 App →「我的 → 設定 → AI 解析（試用）」貼上金鑰 → 按「測試連線」，應顯示「連線成功」。
3. Part 5、Part 6、Part 7、聽力 Part 2、Part 3/4 各故意答錯一題，按「🤖 AI 解析」。
4. 告訴我：每一則解析內容是否合理、有沒有錯誤或看不懂的地方、回應大約幾秒。
5. （選做）把模型換成 Sonnet 5.5 重做一題，比較品質。
