# 07 P1 帳號與隱私 v1.7.0

Type: task（大項，開工前拆成小票）
Status: needs-decision（D-3、D-4）
Phase: P1（11/02–11/29，可以和 06 並行）
Blocked by: 05

設計見 spec §3.6、§3.9。

## 內容

1. **登入**：Firebase Auth 的 Google 登入；可以先不登入，之後再連結帳號。
2. **資料結構與規則**：
   - `users/$uid/...` 逐筆存放；
   - 規則限制 `auth.uid === $uid`，並驗證欄位；
   - 用模擬器自動測試規則。
3. **App Check**：用 reCAPTCHA。
4. **逐筆合併同步**：取代整份覆蓋；衝突時以每筆的 `u` 為準。
5. **舊同步代碼搬移**：照 O-04 的時程，60 天內可讀，再 30 天唯讀，之後關閉。
6. **資料權利**：匯出全部資料、刪除雲端資料、刪除帳號、清除本機資料。
7. **文件**：
   - 隱私權政策、使用條款、商標聲明、內容權利聲明；
   - 聯絡信箱和 GitHub Issues 範本；
   - 常見問題；
   - 威脅模型 `docs/security/threat-model.md`。
8. **發布前資安審查**：延續 v1.3.1 的格式。

## 需要使用者做的事

- 在 Firebase 主控台：
  - 啟用 Google 登入；
  - 把 `realsnova.github.io` 加入授權網域；
  - 註冊 App Check；
  - 貼上規則。

  Claude 會提供規則檔、測試結果和逐步說明。
- 提供聯絡信箱（O-05），並看過隱私權政策。
