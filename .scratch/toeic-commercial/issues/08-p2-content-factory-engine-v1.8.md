# 08 P2 內容工廠與學習引擎 v1.8.0

Type: task（大項，開工前拆成小票）
Status: planned
Phase: P2（11/30–2027/01/31）
Blocked by: 06

設計見 spec §3.2、§3.4、§3.5。

## 內容

1. **題目格式 v2**：加入 `skills`、`lvl`、`ev`、`why`、`rights`；舊題補上來源紀錄。
2. **內容工廠工具**：
   - 批次規格範本；
   - `tools/lint`，擴充重複檢查、位置分布、長度偏差、字彙等級；
   - 盲解工作表產生器；
   - 帳本 `content/ledger.csv`。
3. **App 內審題頁**：讀取待審的內容包，有「同意／有疑問」和備註，可以中斷後繼續。
4. **技能標籤**：約 40 項的分類；AI 標註舊題，抽樣檢查後套用。
5. **掌握度**：類 Elo／Rasch 模型，搭配信心程度顯示。
6. **FSRS**：用在單字和錯題，從 SM-2 變形轉換。
7. **其他學習功能**：
   - 診斷測驗：約 30 題、15 分鐘；
   - 每日計畫 v2：附上選題原因；
   - 遷移練習：答錯後出同技能的新題。
8. **模考報告 v2**：依 Part 和技能、每題作答時間、和前幾次比較。

## 完成條件

- [ ] 模擬學習者 90 天測試：
  - 掌握度能收斂；
  - 沒有任何技能被長期忽略；
  - 每日題量在設定範圍內。
- [ ] FSRS 轉換後，舊單字的下次複習日期合理，不會一次全部到期。
- [ ] 審題頁可以在手機上完成一批抽檢。
