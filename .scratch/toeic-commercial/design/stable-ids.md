# 設計：題目穩定 ID 與紀錄轉換（P1，v1.6.0）

> 狀態：草案（2026-10-11，考前準備，只在 `claude/toeic-p1` 分支）
> 相關：spec §3.1、工作票 06、14；取代 INV-07，新增 INV-13

## 1. 現況與問題

所有學習紀錄都用「題目在陣列裡的位置」當鍵：

| 紀錄 | 鍵的形式 | 例子 |
|---|---|---|
| `S.wb.p5`、`S.wb.l2`（錯題本） | 題目索引 | `"312"` |
| `S.wb.p6`、`S.wb.p7`、`S.wb.l34` | 題組索引-小題索引 | `"14-2"` |
| `S.p5seen`、`S.l2seen`、`S.mockSeen[kind]`（輪替） | 索引 | `"57": true` |
| `S.p6done`、`S.p7done`、`S.l34done`（最佳成績） | 題組索引 | `"9": 3` |
| 題目回報 `toeic900_reports`（本機） | `type` + `key` | `{type:"p5", key:312}` |

這樣做的問題：

1. 只能在陣列尾端加題，不能刪題、重排或依難度分包（INV-07）。
2. 自訂題接在內建題後面，每次內建題增加，都要靠 `shiftForBuiltinGrowth` 把自訂題的紀錄往後搬。題庫越大越容易出錯。
3. 原地修正一題（例如 v1.4.1 換掉 6 題）時，舊紀錄會指到新題目，只能靠 `contentV` 手動清除。

## 2. ID 格式

- **內建題**：`<類型>-<四位數流水號>`，例如 `p5-0312`、`l34-0045`。轉換時依目前的陣列順序編號，所以第一次轉換的流水號＝目前的索引。之後新題拿下一個號碼。
- **題組裡的小題**：`<題組 ID>_<小題序號>`，例如 `p7-0014_2`。Firebase 的鍵不能有 `. # $ / [ ]`（INV-02），所以分隔符號用 `_`，不能用 `#`。
- **自訂題**：`c-<類型>-<8 碼亂數>`，在匯入時就產生並存在自訂題庫裡。和內建題的號碼完全分開，內建題增加時不需要搬任何紀錄。
- **INV-13**：ID 一經發布就不改、不重用。要修正一題的內容（不只是錯字）時，舊題標記 `retired: true`，再新增一題、給新 ID。舊紀錄自然不會指到新內容。

## 3. 資料檔

- 一次性腳本 `tools/content/assign-ids.mjs`：替 `js/data/*.js` 每個項目加上 `id`。只加欄位，不改順序，也不改內容。
- 測試保證：
  - ID 不重複、格式正確；
  - 每個 ID 只對應一題；
  - 已發布的 ID 清單（`content/published-ids.txt`）只增不減。
- `retired` 的題目不出現在練習、模考和組卷，但錯題本仍然可以重考，直到移除。

## 4. 紀錄轉換 `migrateToIds(d)`

在 `sanitizeState` 的最後執行。`load()`、雲端拉取和匯入備份三個入口都會經過這裡。

1. `d.idV === 1` 就跳過，所以可以重複執行，結果相同。
2. 先執行既有的 `shiftForBuiltinGrowth`，讓舊紀錄的索引對到目前的陣列。
3. 依索引找到對應題目的 `id`，把上表每一種紀錄的鍵換掉。找不到的鍵保留在 `d.legacy` 裡（不刪除，INV-03），App 不讀它。
4. 設定 `d.idV = 1`，之後不再需要 `baseN`。`baseN` 和 `contentV` 留著，給舊版 App 讀取時用。
5. 本機題目回報（`toeic900_reports`）也照同樣的方式轉換。
6. 轉換前，把轉換前的整份資料存一份到 `toeic900_pre_v16_backup`（只在本機，不同步）。設定頁可以下載。

## 5. 同步相容

- 新版拉到舊版推上來的資料（沒有 `idV`）：照常轉換，沒有問題。
- 舊版拉到新版推上去的資料（鍵是 `p5-0312`）：
  - 舊版的 `drawRound` 會把非數字的鍵濾掉，所以不會當機；
  - 但錯題本在舊版上會看起來是空的；
  - 如果舊版再推回去，鍵會原樣保留，不會遺失。
- 處理方式：v1.6 和 Service Worker 的更新提示一起上線，盡量縮短新舊版本並存的時間；說明裡也會提醒「請在所有裝置上重新整理」。

## 6. 驗證計畫

| 項目 | 方法 |
|---|---|
| 轉換正確 | 用使用者真實的備份檔（設定頁「匯出備份」）跑 `migrateToIds`，逐項比對：每一筆錯題、輪替、最佳成績都對到同一題的文字 |
| 可重複執行 | 轉換兩次，結果和轉換一次相同 |
| 舊備份 | v1.0、v1.1、v1.3、v1.4、v1.5 各一份測試資料都能匯入、轉換 |
| 自訂題 | 匯入自訂題後內建題增加，自訂題的紀錄不移動 |
| 同步 | 新版轉換後推上去，再用 v1.5 的程式拉下來，不當機、不遺失資料 |
| 退役 | 標記 `retired` 的題目不出現在練習，但錯題本仍可重考 |

## 7. 需要使用者提供

- 一份最新的備份檔：「我的」→「設定」→「匯出備份」。用來演練轉換，只在本機使用，不會上傳或提交到 repo。
