# 威脅模型（v1.7，2026-10-11）

適用範圍：TOEIC 900+ 衝刺（個人使用，D-9：不開放他人、不做帳號登入）。每次發布前照最後一節的清單檢查。

**2026-10-11 決定：端對端加密先擱置**（使用者：「我目前只打算自己用，可以把加密這部分先擱置」）。雲端位置與格式維持 v1.6 的 `sync/<代碼>` 明文，資料庫規則不改。完整的加密實作（PBKDF2＋HKDF、AES-GCM、`v2/<雜湊>`、版本號規則、代碼升級）保留在分支 `claude/toeic-sync-encrypted`，要開放給其他人使用前再接回來。

## 1. 要保護的東西

| 資產 | 存放位置 | 洩漏或被改的後果 |
|---|---|---|
| 學習紀錄（作答、錯題本、單字卡、模考成績） | 瀏覽器 localStorage；開同步時以明文存在 Firebase `sync/<代碼>` | 進度遺失或被竄改；透露讀書習慣 |
| 自訂題庫 | 同上 | 被塞入惡意內容（XSS） |
| 同步代碼 | 瀏覽器 localStorage（只在本機） | 拿到代碼的人可以讀寫全部雲端紀錄 |
| Anthropic API 金鑰 | 預設 sessionStorage，可選擇記住 | 被盜刷 |
| 網站程式與題目 | GitHub Pages（`master`） | 所有使用者執行到惡意程式 |

## 2. 攻擊者與入口

| 攻擊者 | 入口 | 對策 | 殘餘風險 |
|---|---|---|---|
| 猜代碼的人 | 對 Firebase 逐一嘗試 `sync/<代碼>` | 新代碼 20 字元（約 99 位元）；規則禁止列出 `sync/` 底下的位置 | 自訂或舊版的短代碼較容易被猜到：少於 10 字元時介面警告，建議產生新代碼 |
| 資料庫管理者、Google | Firebase 主控台 | 只有使用者自己是管理者；隱私說明寫明「沒有加密」 | 看得到學習紀錄內容（加密擱置，見開頭） |
| 知道代碼的人 | 讀取、寫入惡意紀錄或題目 | 所有外部資料（雲端、備份檔）都經 `sanitizeState`／`cleanBank` 型別檢查；畫面輸出一律 `esc()`；CSP 禁止行內腳本 | 可以改壞或刪除學習紀錄：定期匯出備份 |
| 舊版裝置（v1.6 以前） | 整份覆蓋 `sync/<代碼>` | 新版讀入時做型別檢查、索引轉固定編號後合併 | 舊版不會合併：所有裝置要一起更新 |
| 惡意網頁或擴充功能 | 同一瀏覽器 | CSP `default-src 'self'`、第三方腳本 SRI、no-referrer、不可被框架嵌入 | 惡意擴充功能可以讀 localStorage，不在防護範圍 |
| 供應鏈 | Firebase SDK（gstatic） | 固定版本＋SRI 雜湊 | Firebase 本身被攻破 |
| 程式提交 | `master` | 推送一律要使用者核准；每版有獨立的程式審查 | 審查者也是 AI（spec §8） |

## 3. 資料流

1. 作答 → `save()` 寫 localStorage → 1.5 秒後 `Sync.syncNow()`。
2. `syncNow`：在 Firebase 交易（transaction）裡讀 `sync/<代碼>` → 型別檢查 → 和「上次同步成功的那一份」做三方合併 → 有差異才寫回；另一台裝置同時寫入時 Firebase 用新值重跑合併。成功後套用到本機。
3. AI 解析（自願）：只送出單題的題目、選項、正解、使用者答案到 `api.anthropic.com`；金鑰不進學習紀錄、同步或備份（INV-10–12）。
4. 錯誤紀錄、題目回報：只在本機，使用者自己匯出。

## 4. 不做的事（以及為什麼）

- 帳號登入：D-4 否決。
- 端對端加密：2026-10-11 擱置（只有自己使用），實作保留在 `claude/toeic-sync-encrypted`。
- App Check：需要使用者在 Firebase 主控台設定 reCAPTCHA，等之後再評估；目前的風險（濫用寫入額度）由「位置不可列舉」降低。
- 規則模擬器測試：需要安裝 Java（違反 D-2）。規則檔維持現行版本，以靜態測試（`tests/v1.7-sync.test.mjs` SYNC-11）確認沒有被改動。

## 5. 每次發布前的資安檢查清單

- [ ] 新增或修改的外部資料入口都經過 `sanitizeState`／`cleanBank`，並有測試。
- [ ] 新增的畫面輸出都經過 `esc()`；沒有新增行內腳本或事件屬性（CSP 測試通過）。
- [ ] 沒有把同步代碼、API 金鑰寫進學習紀錄、備份、錯誤紀錄或網址。
- [ ] 第三方腳本仍有 SRI；沒有新增第三方網域（`connect-src`）。
- [ ] 規則檔有改時：在 Firebase 主控台貼上新規則，並用臨時代碼實測後刪除。
- [ ] 隱私說明（設定頁）和實際行為一致；改動時更新 `PRIVACY_UPDATED`。
