# 威脅模型（v1.7，2026-10-11）

適用範圍：TOEIC 900+ 衝刺（個人使用，D-9：不開放他人、不做帳號登入）。每次發布前照最後一節的清單檢查。

## 1. 要保護的東西

| 資產 | 存放位置 | 洩漏或被改的後果 |
|---|---|---|
| 學習紀錄（作答、錯題本、單字卡、模考成績） | 瀏覽器 localStorage；開同步時加密後存在 Firebase | 進度遺失或被竄改；透露讀書習慣 |
| 自訂題庫 | 同上 | 被塞入惡意內容（XSS） |
| 同步代碼 | 瀏覽器 localStorage（只在本機） | 拿到代碼的人可以讀寫全部雲端紀錄 |
| Anthropic API 金鑰 | 預設 sessionStorage，可選擇記住 | 被盜刷 |
| 網站程式與題目 | GitHub Pages（`master`） | 所有使用者執行到惡意程式 |

## 2. 攻擊者與入口

| 攻擊者 | 入口 | 對策 | 殘餘風險 |
|---|---|---|---|
| 猜代碼的人 | 對 Firebase 逐一嘗試位置 | 位置是代碼經 PBKDF2（15 萬次）＋HKDF 推導的 128 位元雜湊；新代碼 20 字元（約 99 位元）；規則禁止列出 `v2/` 底下的位置 | 使用者自訂的短代碼仍可能被猜到：介面警告並提供一鍵升級 |
| 拿到雲端資料的人（含資料庫管理者、Google） | 讀取 `v2/<位置>` | 內容以 AES-GCM 加密，鑰匙只存在使用者裝置；附加資料綁定位置 | 看得到資料大小與更新時間 |
| 知道位置但不知道代碼的人 | 寫入或刪除 `v2/<位置>` | 位置無法從公開資訊得知；寫入的內容解密驗證失敗，App 不套用也不覆蓋，提示「重建」 | 理論上可刪除資料（需先知道位置）；本機紀錄不受影響 |
| 知道代碼的人 | 寫入惡意紀錄或題目 | 所有外部資料（雲端、舊明文位置、備份檔）都經 `sanitizeState`／`cleanBank` 型別檢查；畫面輸出一律 `esc()`；CSP 禁止行內腳本 | 可以改壞或刪除學習紀錄：定期匯出備份 |
| 舊版裝置 | 寫入舊明文位置 `sync/<代碼>` | 新版讀入合併後清空；2027-03-31 後不再讀取，之後規則改為拒絕 | 過渡期內舊位置的資料是明文 |
| 惡意網頁或擴充功能 | 同一瀏覽器 | CSP `default-src 'self'`、第三方腳本 SRI、no-referrer、不可被框架嵌入 | 惡意擴充功能可以讀 localStorage，不在防護範圍 |
| 供應鏈 | Firebase SDK（gstatic） | 固定版本＋SRI 雜湊 | Firebase 本身被攻破 |
| 程式提交 | `master` | 推送一律要使用者核准；每版有獨立的程式審查 | 審查者也是 AI（spec §8） |

## 3. 資料流

1. 作答 → `save()` 寫 localStorage → 1.5 秒後 `Sync.syncNow()`。
2. `syncNow`：讀 `v2/<位置>` → 解密 → 和「上次同步成功的那一份」做三方合併 → 寫回本機 → 有差異才加密寫回雲端（版本號 `rev` 必須加 1，規則檢查；衝突時重讀重合併，最多 4 次）。
3. AI 解析（自願）：只送出單題的題目、選項、正解、使用者答案到 `api.anthropic.com`；金鑰不進學習紀錄、同步或備份（INV-10–12）。
4. 錯誤紀錄、題目回報：只在本機，使用者自己匯出。

## 4. 不做的事（以及為什麼）

- 帳號登入：D-4 否決。代碼即鑰匙的模式下，以加密＋長代碼＋位置雜湊補足。
- App Check：需要使用者在 Firebase 主控台設定 reCAPTCHA，等之後再評估；目前的風險（濫用寫入額度）由「位置不可列舉」降低。
- 規則模擬器測試：需要安裝 Java（違反 D-2）。改為規則檔的靜態測試（`tests/v1.7-sync.test.mjs` SYNC-11）＋上線前用臨時代碼對正式資料庫實測讀寫、竄改、版本衝突，測完刪除。

## 5. 每次發布前的資安檢查清單

- [ ] 新增或修改的外部資料入口都經過 `sanitizeState`／`cleanBank`，並有測試。
- [ ] 新增的畫面輸出都經過 `esc()`；沒有新增行內腳本或事件屬性（CSP 測試通過）。
- [ ] 沒有把同步代碼、API 金鑰寫進學習紀錄、備份、錯誤紀錄或網址。
- [ ] 第三方腳本仍有 SRI；沒有新增第三方網域（`connect-src`）。
- [ ] 規則檔有改時：在 Firebase 主控台貼上新規則，並用臨時代碼實測後刪除。
- [ ] 隱私說明（設定頁）和實際行為一致；改動時更新 `PRIVACY_UPDATED`。
