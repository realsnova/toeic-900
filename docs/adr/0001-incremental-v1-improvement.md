# 在現有 v1 程式上逐步改良

**狀態：已採用，2026-10-06**

產品定位為 A（免費、注重隱私的繁中自學工具，先把閱讀與單字做到商業品質）。我們在現有的原生 JS 程式（`master`，v1.1.0）上逐步改良，每個小版本都能單獨上線，不做框架重寫。商業級評估顯示，主要缺口是內容生產（審題、音檔）、聽力音訊、帳號安全和測試流程，這些都能在現有程式上補齊；重寫要花數個月，期間使用者拿不到任何改善。

本專案的 Codex 分支（`codex/*`）是另一條獨立的開發線。這條改良線不使用、不合併、也不修改它們的程式、題目或文件。

## 考慮過的做法

- **改用 React／TypeScript 重寫**：架構較乾淨，但主要瓶頸不在程式，而且重寫期間無法交付改善。
- **只修止血項目，其餘暫停**：成本最低，但閱讀與單字無法達到商業品質。

## 後果

- 測試必須在不改寫成模組的前提下進行：用 Node 內建的 `node:test` 搭配 `vm` 載入原本的全域腳本。
- 新題目要能和舊題目並存：新題以穩定 ID 為鍵，舊題維持陣列索引鍵。
- 規格與驗證方法見 `.scratch/toeic-v1-improve/spec.md` 與 `verification.md`。
